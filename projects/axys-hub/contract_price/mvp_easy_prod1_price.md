# Easy Price™ — MVP

## Objetivo

Gerar rapidamente uma estimativa paramétrica de custo para um ativo a partir de motores paramétricos pré-configurados.

## Fluxo

### 1. Cadastro

Usuário:

* cria empreendimento;
* cria ativo vinculado;
* define UF;
* define BDI.

### 2. Geração

Usuário acessa:

Orçamento → Importar Paramétrico

Sistema:

* apresenta motores disponíveis;
* usuário seleciona motor;
* sistema processa parâmetros;
* gera orçamento paramétrico.
* app conta o uso.

### 3. Resultado

Sistema apresenta:

* orçamento sintético;
* custos por grupo;
* valor total;
* aplicação automática do BDI.

### 4. Ajustes

Usuário pode:

* alterar BDI;
* recalcular resultado.

Não é permitido:

* editar composições;
* editar insumos;
* editar leis sociais.

### 5. Finalização

Sistema gera:

* planilha Excel;
* proposta comercial PDF;
* resumo executivo.

### Recursos opcionais

Com Easy Branding:

* capa personalizada;
* logomarca;
* fontes corporativas;
* relatórios personalizados.

### Consumo

Cada geração contabiliza um uso do plano contratado.
