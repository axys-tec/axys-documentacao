## O que é?

AxysIFC é o **processador de arquivos IFC** para extração de dados BIM.

**Função:** Ler arquivos IFC (Industry Foundation Classes) e converter em estruturas compatíveis com AxysEasy.

**Saídas:**
- Componentes estruturados (walls, doors, windows, etc)
- Quantidades e propriedades
- Hierarquia espacial/estrutural

---

## 🚀 Como Iniciar

1. Defina mapeamento IFC → Estrutura Axys
2. Documente tipos de elementos suportados
3. Crie exemplos de conversão
